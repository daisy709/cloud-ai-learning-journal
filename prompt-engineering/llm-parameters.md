# LLM Parameters & System Instructions

Notes on configuring large language models effectively.

### ⚙️ Core Parameters
* **System Instructions:** Sets the personality, guardrails, and role of the AI before it interacts with a user.
* **Temperature:** Controls randomness. 
  * *Lower (0.0 - 0.3):* Focused, precise, and factual. Great for coding.
  * *Higher (0.7 - 1.0):* Creative, diverse, and fluid. Great for brainstorming.
* **Top-P (Nucleus Sampling):** Controls the pool of words the model considers based on cumulative probability.
